# 分期成本分析

从借款人视角按实际现金流计算：实际收到的款项为正；利息、手续费、每期还款、保险、担保、账户费以及其他与贷款直接相关的付款，均按实际日期记为负。

## 必需输入

- 借款人实际可支配的净到手金额；
- 每笔付款的金额和日期；
- 所有与贷款直接相关的成本，包括前置扣费；
- 还款方式、末期或气球付款，以及提前结清条款；
- 用户需要复利口径的内部收益率/日期内部收益率、明确标注的简单年化，或两者都要。

若用户只提供每期费率和期数，先索取本金、付款时点、其他费用和提前还款条款；信息不全时不得把结果称为“全部贷款成本”。

## 计算方法

先读 [公式约定](references/formula-contract.md)，再运行：

```bash
python3 scripts/installment_cost.py --input <input.json> --pretty
```

默认报告按实际日期计算的 `xirr_effective_annual_rate`。只有付款间隔确实规则时，才同时报告每期内部收益率、名义年化内部收益率和有效年化内部收益率。

原书简化式：

```text
24 × 期数 × 每期费率 / (期数 + 1)
```

只适用于按月等额本金、每期都按初始本金收取相同费用且没有其他成本的简单平均余额近似。必须标注为“原书简单近似”，不得把它作为唯一或真实年化贷款成本。

现行披露要求与优先使用内部收益率的依据见 [现行利率披露说明](references/official-rate-disclosure.md)。分析日期晚于其中的 `verified_as_of` 时，先复核官方一手来源，再作当前合规判断。

## 输出约定

按以下顺序返回：

1. 规范化的日期现金流表；
2. 日期内部收益率对应的有效年化率；
3. 付款规则时的每期、名义年化和有效年化内部收益率；
4. 仅在假设满足时展示原书简单近似；
5. 广告费率、简单年化和复利年化之间的差异；
6. 未计入成本、提前结清、多个收益率根、日期假设和其他计算限制。

不得把部分成本口径称为全部贷款成本，也不替用户决定是否借款；只能在明确假设下比较成本与条款。
