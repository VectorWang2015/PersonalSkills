# 发布说明

## 2026-09-22：可移植技能包

该流程经过眼科药品、工业阀门、品牌OTC三类公司试读反馈迭代。用户认可按读者理解顺序重写后的版本，并授权同步技能。

收敛后的重点：

1. 用业务、本期变化、原因和风险组织开篇；林奇框架用于分析，不强制向读者展示标签体系。
2. 解释具体的销售、交付、收款及投入过程，合并重复论点。
3. 首次定义主要利润口径，及时解释口径切换，精确核算移至附录。
4. 区分经营现金流与余额、报表费用下降与实际节约、H1实际扣非与H2模型正常化盈利。
5. 文字编辑和图文版式分别检查，用户试读反馈独立于程序检查。

## 包内验证

包含Markdown语义、中文强调、图表内嵌、图片目录范围、输入保护、缺文检查、实际Chrome PDF及交付一致性测试。示例与测试采用合成数据，不包含用户报告、持仓名单、个人目录、模型配置、凭据或代理会话记录。

导出器从技能自身定位样式，使用系统临时目录，支持明确指定Chrome路径。主工作流可以用于任何兼容宿主，工具不是唯一排版方式。

## 适用范围

本次用户反馈覆盖三份单公司报告。Top10模板提供综合报告组织参考，实际输出仍需按批次检查。用户对阅读体验的认可不构成对估值预测、全部来源或投资结果的认证。
