# 用经营驱动建立预测

`cap.medical-institution-valuation.operating-driver-forecast` · revision 2

## 目标

把医疗业务事实连接到分期收入、成本、资本支出、营运资本和现金流，拒绝无解释的统一增长率。

## 共同驱动树

成熟医疗机构必须同时检验：

1. 能否获得并留住患者；
2. 能否有效且有效率地提供服务；
3. 是否有足够人员、设施和设备；
4. 能否及时、合规地获得支付。

按“服务/科室 × 地点 × 支付方”分段，将下列关系量化：

```text
患者或床日数量 × 单位价格 × 收现比例
  -> 收入与现金回收
  -> 变动、固定和阶梯成本
  -> 维持、扩张、合规资本支出
  -> 经营性营运资本
  -> FCFF
```

## 必需输入

- 历史患者、就诊、手术、床日和支付方数据；
- 单位价格、拒付/坏账、回款时间；
- 医生、护理人员、床位、诊室、手术室、设备、营业时间等产能；
- 固定、变动和阶梯式成本；
- 维持、扩张、合规和战略资本支出；
- 应收、存货、经营性应付与周转期；
- 患者来源、竞争、转诊、关键人员、牌照和支付规则及 `as_of`。

## 执行

1. 将历史业务量、价格、收入和收现对账到正常化财务。
2. 对每个分部列需求、市场份额、患者来源、关键人员与物理产能；数量不得超过最小约束。
3. 按支付方预测价格、支付规则、坏账/拒付与回款，不把收入和现金等同。
4. 分开固定、变动和阶梯成本；收入和成本使用一致的名义/实际口径。
5. 资本支出分为强制置换、自主置换、扩张、新服务和合规；说明上线时间与产能影响。
6. 预测经营性营运资本，使用统一符号。
7. 生成基准、上行、下行情景，只改变已登记驱动，并桥接到现金流。

## 竞争分析如何进入预测

旧版五力内容保留为输入，不单独产生“高/中/低”报告：

| 竞争问题 | 模型变量 |
|---|---|
| 现有和潜在竞争者、替代服务 | 患者量、市场份额、价格、获客成本、扩张资本支出 |
| 医生和其他关键供应商 | 产能、薪酬、人员流失、服务可转移性 |
| 医保、商保、自费等支付方 | 单价、病例/服务组合、拒付、回款、坏账 |
| 技术和新服务 | 替代风险、效率、培训、设备与合规投入 |

竞争市场优先使用患者来源、转诊、实际出行和服务替代定义；不用固定 30 分钟半径、行政区或供需倍数。

## 失败信号

- 每年机械使用同一增长率；
- 增长超过医生/床位/设备/网点产能且无扩容；
- 一次性补贴或合同当永久收入；
- 收入增长而成本、营运资本和资本支出不变；
- 当前支付或监管规则无法核验；
- 管理层目标是唯一证据。

## 输出

经营驱动字典、历史量价收现表、产能约束、分期预测、情景桥和当前事实缺口。
