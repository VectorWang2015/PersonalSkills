# 品牌

在分析消费者认知、品牌溢价、提价、折扣、品牌升级或危机时读取。

## 核心模型

品牌是消费者与商家长期交互形成的信用契约。产品、质量、服务、传播、渠道和供应链的每次动作都会增加或损伤认知；同一动作在不同时间和渠道可能产生不同结果。

先区分购买心智：

- 省心型：主要降低搜索成本，重可得性、稳定质量、性价比和效率；
- 悦己型：提供功能、文化、身份、审美或情感效用，重形象一致和价格带。

两者不是收入阶层或品牌优劣，同一消费者会随品类和场景切换。

品牌力最终要落到价格控制：

1. 定价纪律：能否少打折、控制渠道价格和全价销售；
2. 溢价：与功能、规格、渠道相近的替代品相比，消费者是否持续多付钱；
3. 提价/结构：同品直接提价、减少折扣或高端产品占比上升后，需求是否保持。

原书的“认知—优选—品类—身份”层级仅作定性成熟度镜头，不生成总分，也不直接映射估值。

## 输入

- 核心品类、客群、使用场景和可比替代品；
- 3—5 年收入、销量、ASP、毛利、销售费用、退货和现金流；
- 同 SKU/规格跨期、跨渠道建议价与到手价；
- 折扣频次、深度、持续时长、全价售罄和跨渠道价差；
- 复购/会员、品牌搜索、直接流量或其他自然需求指标；
- 公司与经销商库存、窜货、清仓和渠道补贴；
- 质量事故、召回、处罚、舆情及修复结果。

## 执行

### 1. 确认品牌底座

检查规模、分布、持续增速、复购和自然需求。并购、低价补贴、付费流量或单次爆款带来的增长单列。品牌故事没有真实交易支持时，只能是待验证假设。

### 2. 建立价格纪律表

同 SKU 比较必须统一规格、税费、渠道、日期和促销：

| 字段 | 要求 |
|---|---|
| 建议价与到手价 | 分开，后者包含券、赠品和返现影响 |
| 折扣 | 次数、深度、持续时间及销量占比 |
| 全价销售 | 全价售罄/销售占比，不用“从不打折”宣传替代 |
| 渠道价差 | 官方、经销、电商、折扣渠道分别列示 |
| 退货与库存 | 深折是否对应退货、窜货或清仓 |

### 3. 拆 ASP

把平均价变化分为：

- 同品提价；
- 折扣减少/增加；
- 产品、渠道、地域、包装规格结构；
- 汇率、税或会计口径。

提价是否成功，要同时看销量、份额、复购、品牌搜索、毛利、退货和库存。ASP 上升但低价客户流失，不等于品牌力提升。

### 4. 检查动作与时间

列品牌重大产品、质量、服务、传播和渠道动作的时间线。每项记录目标、消费者反馈、经营结果、反证和恢复。单次热点不等于长期认知，单次危机也要结合事件严重性、累积信任和修复结果。

### 5. 辅助层级判断

- 认知：提供基础质量与搜索便利；
- 优选：在可比产品中形成稳定偏好和溢价；
- 品类：品牌与特定功能/品类强绑定，并有自然流量和价格证据；
- 身份：文化/社交效用显著，定价与成本弱相关；
- 二级市场只在有持续真实成交、流动性且排除限量炒作时作为辅助证据。

输出“支持/部分支持/证据不足/反证”，不要给伪精确等级分。

## 不利证据优先

- 收入增长主要来自促销、投放或渠道压货；
- 实现价低于标价、折扣更深或渠道价差失控；
- 提价后份额、复购、搜索或销量明显恶化；
- 销售费用上升却没有新客、自然流量或复购改善；
- 公司库存与经销商库存上升，sell-out 弱于 sell-in；
- 品牌宣称“第一”但没有可追溯份额/排名；
- 高毛利来自产品结构或会计变化，而非消费者付费。

## 输出

- 省心/悦己心智与替代品；
- 规模、自然需求和品牌动作时间线；
- 同 SKU 价格纪律与 ASP 桥；
- 提价/结构后的需求与财务响应；
- 定性成熟度、正证据、反证和替代解释；
- 品牌失效条件和监控指标。

## 停止

规格、促销、渠道或销量不可比时，不给精确溢价/提价结论。质量安全、虚假宣传、召回或监管事项可能实质改变品牌认知时，使用当前一手文件并视需要升级专业复核。
