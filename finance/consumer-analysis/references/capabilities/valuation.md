# 估值

仅在商业模式、增长桥和正常化财务基准就绪，且用户确实要求估值时读取。

## 1. 估值就绪门

至少确认：

- 当前价格/市值及观测时间、复权方式；
- TTM/年度/远期、GAAP/非 GAAP 盈利和稀释股本；
- 分红、回购、增发、期权、可转债和拟发行；
- 净现金/净债务、少数股东和非经营资产；
- 收入、利润率、税、资本开支、营运资金和分部经营桥；
- 熊/基准/牛业务驱动，而非只给倍数。

缺关键输入时输出 `valuation_not_ready`。所有权或股数无法闭合时，可以输出 `equity_value_only` 或分端点敏感性，不给伪精确每股价值。

## 2. 历史回报分解

在同一 EPS 定义和股本口径下：

`股价 = EPS × P/E`

`P1 / P0 = (EPS1 / EPS0) × [(P/E)1 / (P/E)0]`

贡献用乘法桥或对数分解，不把盈利和倍数涨幅直接相加。总股东回报另处理现金分红，并说明前复权/后复权/不复权、拆股、增发和回购。

先正常化盈利：处置、补助、公允价值、减值、重组、股权激励、并购、税率和少数股东单列。负或接近零 EPS 时停止 P/E 和 PEG。

## 3. 方法选择

| 业务状态 | 可考虑的方法 | 必要约束 |
|---|---|---|
| 成熟稳定、现金回报清晰 | 正常化 P/E、FCF yield、简化 DCF/DDM 交叉 | 稳定利润、资本结构和分红/再投资 |
| 高 ROIC 成长 | 经营情景 DCF + 同口径倍数/PEG 交叉 | 增长、再投资率和 ROIC 一致 |
| 亏损/微利成长 | 收入到利润的 top-down 情景、存活/融资稀释 | 不用负 EPS 的 P/E/PEG |
| 周期/恢复 | 中周期盈利、分部恢复桥、FCF/EV 方法 | 不用低谷或峰值盈利作永久分母 |
| 平台/自营/供应链 | 使用匹配商业模式的单位经济和资本强度 | 不把品牌提价逻辑直接移植 |

阶段影响方法选择，但不决定固定“合理倍数”。历史/同业倍数只作带日期的交叉验证，先确认业务模式、会计、增长、风险和利润率可比。

## 4. Gordon 模型

稳定增长股利模型：

`P0 = D1 / (r - g)`，必须满足 `r > g`。

若 `D1 = payout × E1`：

`P0 / E1 = payout / (r - g)`。

如用当期 `E0` 为分母，还需乘 `(1+g)`。`r`、`g` 和 payout 都用小数且时间基础一致。

纯量纲示例：`E1=1.00元/股`、payout=`0.60`、r=`0.08`、g=`0.03`，则 `D1=0.60元/股`、`P0=12.00元/股`、`P0/E1=12x`。这只是公式校验，不是当前参数或合理倍数。

不适用于负盈利、高增长转型、派息/资本结构不稳、周期峰谷或需要大量再投资的公司。`r-g` 很小时必须展示敏感性；`r≤g` 直接停止。

## 5. PEG

`PEG = 同口径 P/E / 预期年化增长率`

明确增长率以 `20` 表示 20% 还是以 `0.20` 表示；两种数值相差 100 倍。PEG 只作交叉描述，不使用固定阈值，也不替代增长持续性、再投资和风险分析。

## 6. 经营情景与倍数/贴现分开

先建经营情景：

- 市场/渗透、份额、价格/结构；
- 销量、店数/同店、用户/人均 GMV 或产能/利用率；
- 毛利、费用、税、资本开支和营运资金；
- 并购、一次性和少数股东；
- EPS/FCF 和增量 ROIC。

再用倍数或贴现参数网格做敏感性。网格不等于选择了一个客观合理倍数。低谷盈利抬高的历史 PE、单季年化或极端分位只能作为警示，不能自动成为目标锚。

## 7. 股本、所有权与净现金

- 每股价值使用可核验的当前股数加已量化稀释；未量化潜在证券列限制，不臆测加入；
- 所有权在多个端点时分别计算，不把混合端点包装成真实上下界；
- PE 乘利润已经直接得到股权价值，不能再机械加净现金；
- 仅当盈利分母持续不含现金收益、现金确属冗余且无受限/运营用途时，才单列净现金调整；
- EV 方法需一致处理净债务、少数股东、联营和非经营资产。

## 8. 输出

- 估值身份、正常化盈利和股本/所有权桥；
- 历史盈利—倍数—分红回报分解；
- 估值 ready/not-ready 与方法理由；
- 熊/基准/牛经营情景；
- 倍数/贴现敏感性和当前价格隐含假设；
- `equity_value_only`、端点或每股输出资格；
- 下行触发器、缺口和非个性化结论。

## 禁止

- 不使用 15—35x、20—40x、25—50x 等固定消费估值带；
- 不把品牌、渠道、供应链按固定倍数排序；
- 不以 PEG≤1、历史中位数或某公司过去高倍数自动判便宜；
- 不把书中 `P/E=1/(r-g)` 简式直接用于估值；
- 不在缺当前价格、股本、单位或盈利基准时给精确目标价；
- 不输出个性化买卖或收益保证。
