# 财务证据

在读取财报、验证增长/护城河、分析库存现金或构建正常化盈利时读取。若输入是 parser 目录，同时读 [解析目录适配](../parser-input-adapter.md)。

## 1. 文档身份门

记录并核对：

- 公司全称、证券代码、合并或母公司范围；
- 年报/半年报/季报、报告期、单季/累计/TTM；
- 全文/摘要、原版/更正版、审计/审阅状态；
- 中国准则/IFRS/US GAAP，GAAP 与非 GAAP 调节；
- CNY/外币，元/千元/百万元，含税/不含税；
- 报表名称、附注/表号、列名、期间和来源页。

单位、版本或表格结构不明时停止关键计算。审计意见要读具体事项、范围与财务影响，不做二元标签。

## 2. 先读文字，再桥数字

竖读同一公司历年管理层讨论，横读同期同业，提取少数核心变量。把管理层主张与产品/渠道/地域分部、量价、利润率、营运资金和现金流一一对应。

每项重大结论至少有一个经营证据和一个财务证据；如果冲突，先列冲突，不替管理层解释。

## 3. 类型化重点

| 模式 | 首要财务/经营证据 |
|---|---|
| 品牌 | 实现价/折扣、量价、毛利与销售费用、复购/自然流量、渠道库存、现金 |
| 平台 | 同口径 GMV、用户、人均 GMV、货币化、商家生态、研发/营销 |
| 自营渠道 | 收入、毛利、履约后贡献、库存/动销/退货、应付与履约资产 |
| 线下连锁 | 平均店数、同店、成熟店贡献、回本、闭店、租赁和加盟商经济 |
| 供应链 | 有效产能/产量、客户、毛利成本桥、应收库存、资本开支、ROIC |

固定利润率或周转范围只可作为有日期的历史案例，不能反向决定公司类型或质量。

## 4. 公式与单位

`同比增速 = 本期 / 上年同期 - 1`

`毛利率 = (营业收入 - 营业成本) / 营业收入`

`费用率 = 对应费用 / 营业收入`

`ASP = 同口径销售额 / 同口径销量`

`周转天数 = 期初期末平均余额 / 同期流量 × D`

`D` 为该流量覆盖的实际天数；若年化，写明方法。余额、流量、币种、单位与合并范围一致。

`净营业周期 = 存货天数 + 应收账款天数 - 应付账款天数`

`ROE = 可归属普通股股东净利润 / 平均普通股权益`

权益接近零或为负时，ROE 失真，改看 ROIC、现金回报或单位经济。分母为零、负值或缺失时不强算。

## 5. 分部与量价

按产品、渠道、地域列收入、增速、毛利率、收入占比和毛利贡献，再用销量×ASP、平均店数×单店、用户×人均 GMV 或产能×利用率×良率×ASP 解释。

合并平均不能掩盖：

- 低毛利业务占比变化；
- 直营/加盟、1P/3P 或线上/线下迁移；
- 并购新分部；
- 消费与 B2B/工程业务混合；
- 汇率和会计重分类。

## 6. 不利证据与正常化

在正面结论前单列：

1. 收入/扣非利润下滑或利润降幅大于收入；
2. 毛利、费用、同店、份额或自然需求恶化；
3. 存货、应收、预付、商誉、资本开支或有息负债异常；
4. 审计、更正、关联交易、质押、持续经营和处罚；
5. 关键市场地位只有公司自述，无可追溯份额/排名。

建立报告→正常化桥：

- 并购并表收入/利润及购买日至期末现金流；
- 处置、政府补助、公允价值、减值和重组；
- 股权激励费用或冲销；
- 费用压缩、税率和少数股东变化；
- 汇率、会计政策和分部变更。

一次性项目和并购不计核心有机增长；费用下降带来的利润增长要与业务增长分开。

## 7. 现金转换与营运资金

`报告现金转换 = 经营活动现金流 / 归母净利润`

它不是质量结论。进一步检查：

- 应付/合同负债增加；
- 应收或库存释放；
- 保证金、票据和受限现金；
- 并购购买日至期末现金流；
- 税、利息、供应链金融和季节性。

输出 reported 与 normalized cash conversion；无法归一化时标证据缺口，不以高比率得分。

库存分原料、在制、成品、发出商品和减值，结合保质期、时尚风险、生产周期与季节。公司发货 `sell-in`、终端动销 `sell-out`、公司库存和经销商库存分开；经销商增加或公司收入增长不能代替终端需求。

## 8. 资本回报与配置

检查 ROE/ROIC、增量资本开支、营运资金、分红/回购、并购对价/商誉、闲置现金和新增产能回报。净现金只提供安全，不自动证明质量；回购导致低/负权益时不要用 ROE 排名。

并购纪律至少看：价格、资金来源、商誉、整合、分部贡献和减值。绿地扩产与并购分开。

## 输出

- 文档身份与来源表；
- 管理层核心变量纵横矩阵；
- 收入—毛利—费用—利润和 reported→normalized 桥；
- 产品/渠道/地域与量价拆分；
- 库存、渠道库存、周转、现金转换和净营业周期；
- ROE/ROIC、再投资、并购与股东回报；
- 不利证据、事实/判断/不确定性和数据缺口；
- 对增长、护城河与估值的验证结论。

## 停止

错误报告、错误单位、错位表格、关键附注缺失或 GAAP/非 GAAP 无法调节时，不输出精确财务或估值结论。复杂收入确认、合并、税务、关联交易或审计事项决定结论时升级专业复核。
