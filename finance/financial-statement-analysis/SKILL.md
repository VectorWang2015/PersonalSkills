# 财务报表分析

## 目标

从财报数据形成可复算、可追溯、有边界的经营诊断。结论回答“发生了什么、主要驱动是什么、哪些风险需继续核验”，不把作者案例阈值当普适规则，也不直接推出买入或卖出。

## 先路由

以下情况不要套用普通工商企业流程：

- 银行、保险、券商等金融企业：说明其资产、负债和现金流分类特殊，需要行业专门指标。
- 未盈利成长企业、平均净资产非正：ROE不是合适入口，转向业务里程碑、融资续航或专门估值分析。
- 用户只问一个公开数字：直接查询并说明口径，无须运行全流程。
- 用户要估值、招股书尽调、个性化买卖建议或舞弊鉴证：转交相应任务；本skill最多提供财报事实和风险线索。

## 输入

至少需要：主体和证券标识、合并或母公司范围、报告期、报表版本、币种和单位，以及三张主表或所需原始数值。缺失会改变计算的输入时，先列缺口或询问，不猜值。

输入来自parser目录、原始文件或粘贴数据时，按 [input-adapter.md](references/input-adapter.md) 处理。parser校验失败的数据只能标为“待核实”。

## 执行顺序

1. 读取 [口径与比较基准](references/capabilities/basis-and-comparison.md)，建立报表身份卡，排除期间、单位、准则和同行不可比问题。
2. 需要解释利润与现金差异时，读取 [三表联动](references/capabilities/three-statement-linkage.md)。
3. 读取 [杜邦驱动](references/capabilities/dupont-driver-diagnosis.md)，用一致的利润/权益口径和平均余额复算ROE及三项驱动。
4. 按任务读取专项能力：
   - 收入回款、利润现金或非经常项目：[现金与利润质量](references/capabilities/cash-earnings-quality.md)
   - 存货、应收或总资产效率：[周转诊断](references/capabilities/turnover-diagnosis.md)
   - 债务、受限现金或再融资：[杠杆压力测试](references/capabilities/leverage-stress.md)
5. 指标突变、明显偏离同行或重大科目无法解释时，读取 [异常分诊](references/capabilities/anomaly-triage.md)。

公式、单位和无效分母规则以 [formulas.md](references/formulas.md) 为准。不要复制数据平台显示的比率而不核对分子、分母。

## 共同规则

- 横向比较选择业务模式、价值链位置、地区、规模和周期暴露相近的同行；数量服从可比性，不强制3—5家。
- 纵向比较覆盖足以观察趋势的期间，并标注重述、并购、会计政策或业务结构断点；不强制3—5年。
- 存量分母通常使用期初期末平均；期中大额增发、并购或强季节性时说明两点平均的局限。
- 收现比的分子是销售商品、提供劳务收到的现金或经核实的等价项目，不是经营活动现金流量净额。
- 零、负或接近零分母不作普通好坏评级；改列绝对额、符号和原因。
- 增长率的负基期即使没有跨零，也不输出普通增长结论；改列前后绝对额、变动额和“亏损收窄/扩大”等方向。
- 年报无法可靠拆分维护性与增长性资本开支时，明确写“无法拆分”。`经营现金流−总购建支出`统一称“扣全部现金购建支出后的保守现金余量代理”；它既非稳态FCF，也非数学上下界。
- 重资产、制造或周期企业的资本开支/转固审查必须覆盖设计与有效产能、利用率、良率、闲置/停建、单位成本、转固后折旧与减值。
- “0.8”“ROE 15%”“现金覆盖大于1”等仅可作为原书时代与案例背景，不能自动判优、排除或投资。
- 异常、存贷双高或高毛利只触发核验；没有审计、监管或司法证据，不称“造假”。
- 不主动写文件、发布报告或执行交易；只有用户明确要求并授权时才保存。

## 输出

按实际任务裁剪，但完整分析至少包含：

1. 报表身份与数据质量：主体、范围、期间、版本、准则、币种、单位、来源定位和校验状态。
2. 核心复算表：公式、原始输入、中间值、结果及无效分母状态。
3. 同行与历史比较：选择理由、趋势和口径断点。
4. 经营诊断：利润—现金桥、ROE驱动、现金质量、周转和杠杆。
5. 异常登记：观察、潜在影响、替代解释、所需证据、已解释/未解释/证据不足状态。
6. 研究状态：在“继续/延后/停止”中选择一个，并给出可观察触发条件；延后或可恢复的停止状态还要写明恢复研究所需的文件、数值或事件。
7. 边界声明：财务分析不等于估值或买卖建议。

Compact模式优先保留结论表、期限桶、异常状态和恢复条件；同一公式或风险不在多个章节重复解释。

## 研究状态门

- **继续**：关键口径已统一，核心计算可复核，未决风险不阻断当前研究。写明继续跟踪的指标及触发延后的条件。
- **延后**：资本开支拆分、期后回款、承诺授信、债务期限或其他重大证据缺失，当前结论会被该证据实质改变。恢复条件必须对应具体资料或阈值方向，例如取得项目资本承诺、期后回款表或未来12—24个月债务到期表。
- **停止**：输入主体/版本不可靠、任务落入金融企业等错误路由、关键数据无法修复，或权威证据已否定继续研究的前提。可修复时写明以更正报告、可靠解析或专门行业模型恢复；不可修复时说明原因。
