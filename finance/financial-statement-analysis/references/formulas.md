# 公式与计算合同

所有货币输入先统一主体、期间、币种和单位。内部计算保留原始精度，最终展示才舍入。

| 指标 | 公式 | 关键口径 |
|---|---|---|
| 资产负债表恒等式 | 资产 = 负债 + 所有者权益 | 允许披露舍入产生的小残差 |
| 平均存量 | （期初 + 期末）/ 2 | 强季节性或期中资本变动需补充说明 |
| ROE | 同口径净利润 / 平均净资产 | 母公司股东视角优先归母利润/平均归母权益；平均权益非正则NM |
| 净利率 | 净利润 / 营业收入 | 披露归母或全部净利润口径 |
| 总资产周转率 | 营业收入 / 平均总资产 | 单位为期间周转次数 |
| 权益乘数 | 平均总资产 / 平均净资产 | 平均净资产非正则NM |
| 杜邦校验 | 净利率 × 总资产周转率 × 权益乘数 | 应与直接ROE在容差内一致 |
| 毛利率 | （营业收入 − 营业成本）/ 营业收入 | 收入为零则NM |
| 现金收入比率 | 销售商品、提供劳务收到的现金 / 营业收入 | 不得用经营现金净额替代；含税、预收和跨期回款可使其大于1 |
| 净利润现金含量 | 经营活动现金流量净额 / 净利润 | 零、负或近零利润改看绝对额，不作普通优劣评级 |
| 扣非净利润占比 | 扣非净利润 / 净利润 | 负或近零利润改列绝对额；跨准则先核对定义 |
| 存货周转率 | 营业成本 / 平均存货 | 不用营业收入替代营业成本 |
| 贸易应收周转率 | 营业收入 / 平均贸易应收 | 贸易应收按实质纳入应收账款、应收票据、应收款项融资，避免重复和非贸易应收 |
| 周转天数 | 期间天数 / 周转率 | 年度可用365；其他期间披露实际天数 |
| 有息负债率 | 实质带息债务 / 总资产 | 核对借款、债券、租赁及其他付息义务；三科目近似会低估 |
| 现金债务覆盖 | 可动用现金及现金等价物 / 实质带息债务 | 扣除受限资金；无带息债务时报告事实，不显示无穷大 |
| 标准利息保障倍数 | EBIT / 利息费用 | EBIT与利息必须同期间；利息费用用正数支出量，口径不明则不算 |
| 现金利息覆盖辅助指标 | 经营活动现金流量净额 / 已付利息现金 | 与标准EBIT/利息保障倍数分开命名；若只有利润表利息费用，只能明确标为替代口径 |
| 扣资本开支前现金参考量 | 经营活动现金流量净额 | 尚未扣除维持经营必需的资本开支，不是自由现金流 |
| 扣全部现金购建支出后的保守现金余量代理 | 经营活动现金流量净额 − 购建长期资产支付的现金 | 观察当期全部现金购建支出后的余量；既非稳态FCF，也非数学上下界 |

## 无效或危险计算

- 必需输入缺失：返回缺口。
- 分母为零或绝对值低于任务的重要性阈值：标记 `NM`。
- 分母为负：保留数学结果只会误导时，标记 `NM` 并解释符号。
- 增长率基期为负时，即使本期仍为负且没有跨零，普通百分比也可能把亏损收窄显示成“负增长”；标记 `NM`，改列绝对变动与方向。
- 跨币种、单位或期间：先转换；转换依据不明则停止。
- 期初期末合并范围不同：先重述或标记不可比。

## 资本开支区间

若维护性资本开支无法由年报可靠识别，明确写“无法拆分”，并并列两个不同用途的量：

- 经营活动现金流量净额：扣资本开支前现金参考量。
- 经营活动现金流量净额减总购建长期资产现金支出：扣全部现金购建支出后的保守现金余量代理。

第二项不得称为下界，也不得称为稳态自由现金流；维护资本开支、票据结算购建和资产处置等会使其不具数学边界含义。两项用于资金覆盖和敏感性讨论，不是估值结论。已承诺未支付的资本开支另列，不能从历史现金支出中消失。

## 作者阈值

原书出现现金比率约1、个人最低0.8、ROE 10%/15%/20%和3—5比较原则；它们受作者偏好、样本和时期影响。原书第二个ROE档还印成不可成立的 `20%＜ROE≤15%`。运行时不得把这些数字编译成普适投资门槛。
