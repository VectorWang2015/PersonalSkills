# 带息债务结构与现金覆盖压力测试

Status: `draft`

Capability ID: `cap.seven-steps-financial-statements.leverage-stress`

## 触发

资产负债率高、ROE由杠杆驱动、存贷双高、短债压力或再融资依赖。

## 步骤

1. 将重大负债分为实质带息融资、经营性无息负债和未决项目。
2. 核对短期/长期借款、债券、租赁及其他付息义务，计算带息负债率。
3. 将现金分层：自由可调度、受限/保证金、专项募集或专户用途、境外管制、少数股东子公司不可上划、最低运营现金。只有经证据确认可调度的部分进入可动用现金覆盖。
4. 强制列出资本承诺、担保、回购/诉讼等表外或或有现金义务；无法量化时也要说明性质、受益人、期限和触发条件。
5. 分列未来12个月、12—24个月及更长期到期，检查币种、浮动利率、契约和交叉违约。
6. 标准利息保障倍数使用EBIT/利息费用；经营现金/已付利息仅作现金口径辅助指标，必须分开命名和展示。利息口径不清时停止计算。
7. 核对授信是否为已承诺、不可随意撤销且满足提款条件；区分总授信、未使用额度与可立即提款额度，并检查历史续作/续贷和再融资集中期。
8. 将资本开支、营运资本、分红和到期债务对现金的竞争纳入基准与下行情景。
9. 无息负债上升时检查供应商、客户、关联方、履约义务和账期；不自动解释为议价权。
10. 存贷双高时调查低息融资、汇率套保、受限资金、资金归属等替代解释。

## 输出

债务分类、现金可用性分层、带息负债率、可动用现金覆盖、资本承诺与担保/表外义务、期限缺口、标准利息保障倍数、现金口径辅助覆盖、承诺授信与续作条件、再融资情景。

## 边界

覆盖倍数大于1不等于绝对安全；小于1也不等于立即违约。银行、保险、券商的负债是业务结构的一部分，必须转专门模型。复杂结构化融资、交叉违约或债务重组应专业复核。
