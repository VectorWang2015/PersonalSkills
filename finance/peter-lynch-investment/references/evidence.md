# 来源证据与合并 lineage

## 来源身份

本 skill 以《彼得·林奇的成功投资》2010 年机械工业出版社中文电子版为来源。TXT SHA-256 为 `85bca43c1a0c9a3446070b0da67138c8d96b8c9e8c0ddaf2bbbf9e8416ac780d`，EPUB SHA-256 为 `9ec086ff1f3ac728f0cad2f6fe3ad416efd588aecdb90669549aa3e753d27316`。完整便携清单见 [source-manifest.json](source-manifest.json)。

以下均为独立转述；不复制长篇原文。`explicit` 表示作者直接主张，`synthesized` 表示由多处原书结构综合，`inferred` 表示为满足当代运行和金融质量门所做的设计。

## 当代运行推断

以下不是作者原话，来自 book2skill 金融质量门和本轮产品设计：

- 报告身份、版本、币种、单位、会计准则和价格 `as_of` 是计算前置条件；
- 原书中文“稳定增长型”在运行时称为“中速增长型（stalwart）”，避免与 high-quality 质量属性混淆；
- 主类型以多个可比期间的正常化收入、EPS/利润、核心量价和周期机制判定；高ROE、品牌、渠道和现金不单独支持增长类型；
- 当前核心与利润下降且无充分一次性或周期解释时，优先缓慢增长/成熟现金牛候选或类型不确定；
- 负或零 EPS 时 P/E/PEG 标记 `N/M`；
- CAGR 仅在正且可比端点使用；
- 净现金需处理受限现金、经营现金、全部有息债务、租赁和少数股东；
- 当前次类型只有在独立利润、现金贡献、投入资本回报和持续性均验证后成立；
- 单一报告分部下，产品收入和毛利不能替代产品级资产、负债、净利润、现金贡献与 ROIC；
- 研究状态使用简洁中文，且不自动生成交易指令；
- 正式目标价和行业特殊估值路由到相应兄弟能力。

## 冻结后 legacy 合并证据

旧实现提供八个 atomic 主题，但全部缺 frontmatter。其有用操作内容已按 comparison lineage 合入：

| Legacy 内容 | 保留 | 删除 |
|---|---|---|
| 六类公司 | 简洁术语、类型特定问题 | 历史增长率和固定复评频率 |
| 13 条准则 | 利基、复购、复制、资本配置等问题 | 5/8/10 条计分、名称/无聊直接加分 |
| 6 种危险股 | 热门故事、无关并购、客户集中等反例 | 危险项计数和“全部安全”结论 |
| PEG | P/E、增长一致性、周期低 P/E 警告 | 所有 PEG 分档和买卖标签 |
| 卖出 | 分类信号、原论文和机会成本 | 固定数字、立即/减半/必须卖出 |
| 组合 | 持仓论文盘点和经济驱动暴露 | 固定数量、配比、满仓和止损禁令 |
| 12 个价格误区 | 用户语言与反例 | 用新的价格口诀替代公司证据 |
| 鸡尾酒会 | 仅作为从众偏差历史例子 | 四阶段买入/持有/减仓/卖出映射 |

## 实战使用证据的地位

冻结后扫描到 54 份文件名明确带“林奇/彼得林奇”的历史报告。它们证明用户确实需要分类、风险检查、估值和持有复核，也显示旧模板把 13 条、PEG 和动作阈值传播到输出。报告不是独立评测，也不能覆盖原书证据；仅用作 merged 的开发回归。

完整能力对齐的预发布材料位于本轮私有 comparison 工作目录，不复制到运行热路径。v4 匿名聚合发布结果与逐卡边界见 [release-evaluation.md](release-evaluation.md)。
