# 增长、财务与估值一致性

## 何时使用

需要判断增长故事、利润质量、财务承受力和当前价格要求是否互相支持时使用。它是预期一致性检查，不是完整目标价模型；正式合理价值、DCF 或方法选择应转综合股票估值能力。

## 先建立数据身份

读取 [当前数据契约](../current-data-contract.md)，为每个数值记录主体、报表、期间、版本、币种、单位、股数口径、来源和 `as_of`。

## 一、增长桥

先用多个可比期间建立正常化收入、EPS/利润和核心业务量价序列，再把历史和预测增长拆开，并解释来源。高 ROE、品牌、渠道、现金和低负债属于质量属性，不证明中速增长型（stalwart）。

```text
收入增长
  = 价格 + 销量/使用量 + 市场份额 + 新区域/门店/客户 + 并购

利润增长
  = 收入变化 + 毛利率/产品结构 + 费用效率 + 融资成本
    + 亏损业务关闭/恢复 + 税项 + 一次性项目

每股收益增长
  = 利润增长 + 回购/增发/股权激励等股数变化
```

每项标记历史事实、管理层目标或分析情景。行业增长不等于公司盈利增长；总量增长也可能被利润率、资本需求或稀释抵消。

收入、销量、产能、投产或客户认证只能证明业务活动扩张。只有独立利润、现金贡献、投入资本回报和跨期持续性都得到验证时，才能把该业务视为当前成长/稳定次类型；否则只写“待验证成长选项”或“结构性模块”。

## 二、利润质量与财务承受力

至少检查适用项目：

- 法定利润与扣除重大一次性项目后的差异；
- 经营现金流与利润的桥接，营运资金是否造成暂时波动；
- 自由现金流的资本开支口径；
- 现金、受限现金、全部有息债务、租赁和到期结构；
- 库存相对销售、计价政策、季节性和贬值风险；
- 应收、客户集中、担保、养老金、诉讼和其他或有负债；
- 回购、分红、并购和增发如何改变每股价值。

若公司只披露一个报告分部，产品收入和毛利不能替代产品级营业利润、净利润、现金流、资产、负债、投入资本与 ROIC。把这些缺口放进一致性结论和最强反例。

困境公司先回答能否活到修复完成；资产公司先回答扣除负债和实现成本后的可实现净值。

## 三、公式与单位

### P/E

```text
P/E = price_per_share / EPS_per_share
```

- price 与 EPS 必须是同一股类、同一币种/股；
- 价格记录市场和观测时间；
- EPS 明确年度、TTM 或预测期间，以及基本或稀释；
- EPS 小于或等于零、被重大一次性项目支配或不可比时标记 `N/M`，不输出正常 P/E/PEG 结论。

### 历史 EPS CAGR

```text
CAGR = (comparable_EPS_end / comparable_EPS_start)^(1 / years) - 1
```

仅在两端为正、期间长度明确且会计范围可比时使用。否则展示逐期路径或改用更合适的经营指标。预测增长与历史 CAGR 不得混成一个数字。

### 产品或分部材料性

```text
materiality = relevant_segment_metric / consolidated_metric
```

分子分母须同期间、币种、单位和合并层级；收入贡献不能冒充利润贡献。

### 净现金/股

```text
net_cash_per_share
  = (cash_and_equivalents
     + explicitly_available_securities
     - defined_interest_bearing_debt)
    / diluted_shares
```

同时披露受限现金、经营所需现金、租赁/少数股东、债务范围和资本配置。不能照搬书中只减长期债务的粗略案例，也不能把全部现金视为免费赠送。

### 自由现金流

明确选择并命名：

```text
reported_FCF = operating_cash_flow - total_capex
```

或

```text
maintenance_FCF = operating_cash_flow - estimated_maintenance_capex
```

维护性资本开支未知时返回缺口或区间，不以零替代，也不把两种口径混称。

### 原书式增长调整比率

仅在用户要求或用于解释来源时展示：

```text
source_style_ratio
  = (EPS_growth_percentage_points + dividend_yield_percentage_points) / P/E
```

15% 写作 15 个百分点，不是 0.15。这个比率与常见 `PEG = P/E / growth_percentage_points` 方向相反，不得都称为 PEG，也不得使用固定“低估/合理/高估”档位。

合成量纲检查：价格 30 元/股、TTM 稀释 EPS 2 元/股，则 P/E 为 15 倍；若可比 EPS 两年前为 1.50 元/股、当前为 2.00 元/股，则 CAGR 约 15.47%。假设股息收益率 1%，原书式比率约为 `(15.47 + 1) / 15 = 1.10`，仅作预期诊断。

## 四、分类适配

- 缓慢增长型：分配覆盖、资本配置、债务与实际现金收益；
- 中速增长型（stalwart）：多期正常化收入与EPS/利润由核心业务持续中速增长，随后再看利润质量和当前价格；
- 快速增长型：复制质量、增长持续期、再投资效率、融资与稀释；
- 周期型：正常化利润、供需/价格/库存/产能，低 P/E 可能在利润峰值；
- 困境反转型：流动性、债务期限、修复情景和股权剩余价值；
- 隐蔽资产型：可实现净值、负债和兑现路径，P/E 可为次要。

若当前核心收入与正常化利润下降，且缺少充分的一次性、并购口径或周期证据解释，不得用高 ROE、品牌、渠道或现金把公司归为中速增长型；优先考虑缓慢增长型、成熟现金牛或类型不确定。

## 五、形成一致性结论

至少给出一个保守、基准、乐观情景或反向预期检查，说明结论对增长、利润率、资本需求和估值倍数的敏感方向。

输出状态：

- `一致`：主线、财务承受力和价格要求相互支持；
- `待验证`：关键假设尚未被执行数据验证；
- `不一致`：增长故事与利润、现金、资产或价格要求冲突；
- `不适用`：指标不适用于当前机制；
- `数据不足`：身份或输入不足。

## 禁止

- 固定 PEG 分档、买入线或卖出线；
- 跨行业无调整比较倍数；
- 负 EPS 报告“负 P/E 很便宜”；
- 用单季、累计、TTM 和年度混算；
- 把低 P/E 周期股自动判为低估；
- 仅凭该启发式给精确目标价、仓位或交易命令。
