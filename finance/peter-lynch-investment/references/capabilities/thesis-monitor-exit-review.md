# 主线监测、重分类与退出

## 何时使用

用户已有持仓或历史研究，需要根据最新财报、经营事件、竞争变化或估值更新判断原论文是否仍成立时使用。

## 前置条件

必须有可恢复的旧论文，至少包含：日期、公司类型、价值驱动、成功条件、关键风险和下一检查指标。若没有，先用研究主线能力重建，不要事后伪造当初理由。

## 执行流程

### 1. 冻结旧论文

先展示旧版原文或结构化摘要，不根据当前价格和新闻静默改写。

### 2. 核对可比性

确认当前与旧期的主体、合并范围、报告版本、期间、币种、单位、会计政策、重述和并购断点。

### 3. 逐项更新

每条旧假设标记：

- `已验证`：新证据继续支持；
- `转弱`：仍可能成立，但证据变差；
- `已证伪`：核心前提已被推翻；
- `待检验`：计划尚未到验证期；
- `已被新机制替代`：公司机制或分类已经变化。

管理层计划、在建项目、降本目标和协同承诺在落地前不能标成 `已验证`。

### 4. 重跑分类

检查公司是否从快速增长转为中速/缓慢，从周期转为困境，从困境修复为正常周期/中速增长公司，或因资产处置失去资产型特征。

重分类先更新多个可比期间的正常化收入、EPS/利润与核心量价。高 ROE、品牌、渠道和现金只能更新质量属性；若核心与利润下降且无充分一次性或周期解释，优先转向缓慢增长/成熟现金牛候选或类型不确定，而不是继续保留中速增长型。

收入、销量或产能扩张但独立利润、现金贡献、投入资本回报和持续性未验证时，不得新增成长次类型，只保留待验证成长选项。若公司只有一个报告分部，把产品级资产、负债、净利润、现金贡献和 ROIC 缺口列为最强反例。

### 5. 按当前类型检查

| 类型 | 重点监测与论文失效信号 |
|---|---|
| 缓慢增长型 | 分红/回购覆盖、份额、再投资纪律、债务、无关并购 |
| 中速增长型（stalwart） | 多期正常化增长、核心量价、利润与现金转化、新产品、资本配置、价格要求 |
| 快速增长型 | 新单位复制、同店/同客户、单位经济、剩余空间、人才、融资与稀释 |
| 周期型 | 终端需求、价格、库存、订单、产能利用率、新增产能、竞争与资本开支 |
| 困境反转型 | 现金跑道、债务期限、契约、重组里程碑、稀释、业务恢复；修复完成即重分类 |
| 隐蔽资产型 | 可实现价值、负债/税费/实现成本、出售证据、治理、稀释和资本配置 |

成熟核心持续下降不自动等于困境反转型。只有生存压力和可验证修复机制成为价值主线时才使用困境反转分类；否则先降级原类型或保持不确定。

这些是信号族，不使用原书案例中的固定百分比、季度数、分析师数、机构比例或增发比例。

### 6. 更新估值与下行

只用更新后的盈利、资产和风险假设复核价格要求。价格变化是复核触发器，不是论文对错的证据。

### 7. 比较机会成本

只有在相同风险、期限、数据质量和授权边界下，证据更强的替代机会才构成机会成本。另一只股票近期涨得更多或故事更热门不算。

## 输出状态

```text
旧论文日期与分类：
关键假设差异表：
当前主/次类型：
待验证成长选项/结构性模块：
继续支持的证据：
论文失效或削弱的证据：
估值与下行变化：
机会成本：
状态：论文成立 / 待观察 / 论文转弱 / 论文失效 / 需要重分类 / 证据不足
会改变状态的下一触发器：
```

上述状态不自动生成交易指令。

## 明确排除

- 因已经上涨很多自动止盈；
- 因已经下跌很多自动止损或认为不能再跌；
- 等回到买入价才卖；
- 固定持有期、涨跌幅或 P/E/PEG 卖出线；
- 鸡尾酒会、分析师数量或媒体热度决定退出；
- “永不止损”或“下跌必须加仓”的绝对规则；
- 未经授权的立即卖出、减半、分批止盈或下单。

## 停止或转交

- 找不到旧论文；
- 当前报告与旧期无法形成可比口径；
- 破产、重大诉讼、监管或损失上限无法估计；
- 用户要求实际交易但未授权。
