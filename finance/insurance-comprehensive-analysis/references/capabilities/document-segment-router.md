# 文档身份、全报告扫描与分业路由

所有报告分析先运行。本模块决定“看了什么、还没看什么”，不把摘要、截图或单一章节当作整份报告。

## 身份卡

记录：法律主体、证券代码、集团/母公司/子公司、报告类型与期间、全文/摘要、原版/更正版、审计状态、币种和单位、合并/单体、时点/期间流量、会计执行模式、偿付规则，以及关键事实页码/表名/列名或文本行号。

优先使用目标期间最新更正版全文。主体、版本或比较期歧义足以改变结论时停止精确分析。

## 宣布缺失前的强制扫描

按以下顺序搜索并保留简短搜索日志：

1. 集团经营摘要、财务摘要、管理层讨论与分析；
2. 资本管理、偿付能力、风险管理和监管指标章节；
3. 每个主要保险子公司的经营、资本和偿付能力章节；
4. 母公司单体资产负债表、利润表、现金流量表；
5. 母公司投资收益附注、利润分配附注及报表索引；
6. 关联方关系及其交易、母公司与子公司的股利收入明细、应收股利附注；
7. 长期股权投资成本法会计政策、集团母公司可动用资金或资本资源章节；
8. 用同义词全文检索，例如“核心偿付能力”“综合偿付能力”“股利收入”“子公司分红”“投资收益”“关联方”“应收股利”“可动用资金”“宣告分派”。

只有完成上述相关范围后，才可写“整份报告未找到”。搜索日志至少写明检查的章节/页码范围、关键词及结果。

## 披露层级

- **未在摘要披露**：摘要没有，但全文其他位置已找到，或全文搜索尚未完成。
- **未在当前章节披露**：当前表或章节没有，不代表其他章节没有。
- **整份报告未找到**：完成强制扫描和同义词检索后仍未找到；同时列已查范围和可能需要的补充文件。

禁止把“未在摘要披露”缩写为“报告未披露”。如果只获得摘要、截图或节选，只能说明该材料未见。

## 股利证据层级

全文搜索时分别记录：

1. 母公司投资收益附注中的股利收入合计是否可得；
2. 关联方交易附注中的主要子公司逐家确认明细是否可得；
3. 成本法会计政策是否说明宣告分派时确认投资收益；
4. 年度可动用资金表是否列子公司分红流入及逐家明细；
5. 每家子公司的宣告决议、支付及母公司实际到账证据是否可得；
6. 母公司现金流量表和应收股利能提供何种旁证。

不得因后续层级不可得而声称较早层级也缺失。成本法政策提供一般宣告确认节点，不替代逐家决议；“年度可动用资金表所列子公司分红流入”按该表证据强度使用，不升级为逐笔银行到账。投资收益、关联方明细、年度资金流入、现金流总额和EV口径之间的差额保留为未归属或跨口径。

## 解析目录兼容

用户提供 `financial-pdf-parser` 目录时：

1. 读 `analysis_context.md` 和 `validation/validation_report.md`；
2. 用 `tables_merged` 复算；
3. 用 `chunks.jsonl` 或 `document.md` 做全报告检索；
4. 关键事实回到原表或原页；
5. 校验失败的数据标“待核实”。

解析结果中的页码可能是PDF页、印刷页或数组索引，引用时标明页码体系。

## 分业

| 分部 | 路由 | 不得默认 |
|---|---|---|
| 财险 | 经营质量财险模式、投资与ALM | 不套寿险EV/VNB或长期利润释放 |
| 寿险/长期健康险/年金 | 经营质量寿险模式、价值与资本、利润释放 | 不套旧剩余边际和固定收益率 |
| 短期健康险 | 按合同期限、计量模型和公司分部披露 | 不凭公司名称决定 |
| 混合保险集团 | 各分部先分析，再合并投资、资本、内部抵销和少数股东 | 不用单一分部代表集团 |
| 综合金融集团 | 优先读取业务净利润至集团归属贡献的现成勾稽 | 不把银行或其他业务全体股东利润直接并入集团归母 |

## 输出

综合金融集团第一张核心表优先列：业务/分部净利润、归属于集团母公司的对应贡献、少数股东、其他业务及合并抵销、集团合计；报告有正式勾稽时必须使用。其他任务给简短身份/路由表，列报告身份、分部、会计与监管模式、已查范围、可用/缺失指标、加载模块和阻断项。紧凑任务不展开搜索过程，但对任何“整份报告未找到”的结论必须保留检查范围。
