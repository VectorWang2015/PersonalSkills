# EV、VNB与偿付资本

## EV/VNB身份和符号

记录集团/寿险范围、报告日、币种、单位、精算审阅、调整净资产、毛/扣偿后有效业务价值、毛/扣偿后VNB、持偿成本、风险分散、关键假设和公司敏感性。

持偿成本只选一种一致约定：括号负数按带符号值加一次，或把正的成本绝对值减一次。检查：

- 扣偿后有效业务价值 = 毛有效业务价值 - 正的持偿成本；
- 寿险EV = 调整净资产 + 扣偿后有效业务价值；
- 扣偿后VNB = 毛VNB - 正的新业务持偿成本。

已披露扣偿后数值不得再扣。集团EV按公司披露加入其他业务和集团调整，内部股息不得重复计入。

## EV变动

公司正式变动表优先：

`期末EV = 期初EV + 全部带符号变动项`

分类为预期回报、新业务/分散、经验、假设/模型、投资/市场、一次性和资本变动。不以3%-4%、5%或11%替代正式表。有效业务价值预期回报不等于当期现金或利润释放；敏感性只用同公司同报告披露或明确标注的分析压力。

## 偿付能力搜索门

在称个体偿付能力数据缺失前，必须检查：

1. 集团经营摘要和监管指标；
2. 资本管理/偿付能力章节；
3. 每个主要保险子公司的经营或资本章节；
4. 报告后部资本管理附注、风险管理附注及全文同义词检索。

摘要只给集团数时，应写“未在摘要披露”，继续搜索全文；不得写“整份报告未披露”。

## 资本表

资本表按以下优先级列示：

1. 每个主要保险子公司；
2. 保险集团；
3. 其他受监管实体（与任务相关时）。

核心列包括：实体、核心偿付能力充足率、综合偿付能力充足率、报告时点、报告列示的监管门槛和来源页码/表名。任务要求完整监管达标判断或报告直接披露时，再加入风险综合评级。报告只披露部分字段时保留空缺和披露层级，不复制集团数据。

集团比率不能替代个体比率。子公司分红、增长或补资约束必须用该子公司的资本与监管信息判断。

现行达标需同时满足：核心不低于50%、综合不低于100%、风险综合评级B类及以上。还要检查资本分层、最低资本、流动性、集中度、监管措施、业务增长、再保险、分红和补资。现行规则见 [../current-standards.md](../current-standards.md)。

紧凑任务若只问核心/综合比率、时点和报告门槛，不为未要求的风险评级单独扩展搜索日志或缺失段落；这不改变进行完整法定达标判断时必须检查评级的规则。

保单未来盈余按规则Ⅱ分级，不等于旧剩余边际整体转资本。最低资本是监管要求，持偿成本是EV中的资本占用调整，两者不得等同。

## 停止条件

- 集团/子公司范围混用；
- 毛/扣偿或符号不明；
- 未完成全文搜索却要求断言缺失；
- 缺正式EV变动表、敏感性或偿付报告却要求精确结果；
- 当前规则或公司过渡处理未确认。

紧凑输出优先给子公司资本表、集团汇总和最相关的资本/分红约束；详细EV变动按需展开。
