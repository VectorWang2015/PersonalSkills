# 利润释放、服务结果与母公司分红链

本模块区分现行保险服务结果、公司管理利润、子公司上划和母公司法定/现金分红能力。先读 [../current-standards.md](../current-standards.md)。

## 保险服务结果桥

分别取本期和上期同口径金额，计算带符号变化额，按绝对变化从大到小排序。至少检查：

1. CSM当期释放；
2. 非金融风险调整释放或变化；
3. 亏损部分确认与转回；
4. 当期服务赔付、费用和其他经验差异；
5. 过去服务相关履约现金流变化；
6. 保险获取现金流分摊；
7. 再保险影响；
8. 其他服务项目。

服务结果同比变化由这些项目共同解释。CSM释放增加不等于保险服务利润必然增加，不能以CSM单项概括。

集团总桥与长期合同内部桥必须分层展示、分别勾稽，不能重复相加。例如，保费分配法、非保费分配法和分出再保险是集团总桥；亏损部分、风险调整、经验差异和CSM释放是非保费分配法合同的内部桥。

CSM变动表披露充分时另行重建：

`期初CSM + 新合同 + 适用利息 + 未来服务相关变动 + 汇率/其他 - 当期服务确认 = 期末CSM`

CSM余额桥与当期保险服务结果桥是两个问题，不得混写。

寿险数据充分时必须分别闭合三条桥：

1. `CSM摊销 + 非金融风险调整变动 + 营运偏差及其他披露桶 = 保险服务结果`；
2. `保险服务结果 + 投资服务业绩 + 其他税前项 = 税前营运利润`，再经所得税到营运利润，并加短期投资波动和一次性项目到净利润；
3. `期初CSM + 新业务 + 利息 + 估计变更 + 其他 - 摊销 = 期末CSM`。

三条桥分别回答当期服务、管理利润和存量滚存，不得横向相加。任何一条缺数据就停在可得层，不用另一条桥补洞。

## 净利润和公司管理利润

净利润桥仍检查保险服务、保险财务、投资买卖/公允价值、利息/股息/租金、信用/减值/汇兑、处置/并表/会计变动、税、少数股东和一次性项目，并按绝对变化排序。

混合税前项目、所得税和少数股东损益时，使用“税前利润至归母利润同比勾稽桥”；没有正式逐项税后归因时，明确不做逐项税后归因。

公司明确披露营运利润、旧剩余边际或其他管理指标时，可以重建其带符号调整桥和余额桥，但不得代替新准则CSM或保险服务结果。缺分项时不按5%、65%-75%或其他历史比例代填。

## 母公司分红证据链

股东现金分红通常取决于母公司单体。宣布数据缺失前必须扫描母公司单体报表、投资收益附注、关联方关系及其交易、长期股权投资成本法会计政策、年度可动用资金/资本资源表、应收股利和利润分配附注。

### 1. 子公司上划

先交叉勾稽两类披露：

1. 母公司投资收益附注中的子公司、结构化主体或类似范围股利收入合计；
2. 关联方交易附注中主要子公司的逐家股利收入确认明细。

分别列本期、上期、同比、单位、范围和页码。只有期间、单位及合计与明细范围可交叉解释时才复算：

`未归属差额 = 投资收益附注合计 - 关联方逐家明细合计`

差额只可写成“结构化主体、未在关联方表单列的其他子公司或口径差异中的未归属项”。报告没有进一步证据时，不得把差额全部强制归为结构化主体，也不得分摊到已列子公司。

随后至少明确三类基础披露层级：

- **合计确认金额可得**：只能证明报告列示范围的会计确认合计；
- **主要子公司确认明细可得**：能说明已列主要子公司的确认金额，不能据此称逐家宣告日期、支付或到账已证明；
- **逐家宣告/支付/到账证据不可得**：只把缺口留在相应层级，不能倒推前两层也缺失。

成本法会计政策如果规定被投资单位宣告分派时确认投资收益，只能建立“宣告—确认”的一般节点；没有逐家决议时，不能用政策替代各子公司的宣告日期或金额。

报告若另有“年度可动用资金表所列子公司分红流入”，固定按该管理层年度资金流入表的证据强度表述：它支持该表所列年度流入和逐家构成，但不等于取得逐笔银行回单，也不自动补齐损益确认或逐家宣告决议。

继续检查子公司批准/支付公告、母公司现金流量表、应收股利、可分配利润、现金、偿付能力、资本计划、监管限制和少数股东。现金流项目混合利息或其他投资收益时只能作旁证；期末应收股利低也不能单独证明全部现金到账。

逐家年度资金流入合计与以下口径不一致时分别列示，不猜来源：

- 与母公司现金流量表投资收益收现总额的差额：未归属现金流差额；
- 与母公司投资收益的差额：权责发生制与现金流、范围及时点的跨口径差额；
- 与EV变动或精算口径分红的差额：精算范围、时点或四舍五入的跨口径差额。

子公司利润、EV、VNB或CSM不等于已经上划的母公司现金。

### 2. 母公司单体资源

至少检查：

- 母公司净利润及同比；
- 以前年度亏损和期末未分配利润；
- 法定/任意公积及本期提取；
- 现金及等价物、受限资金和现金流；
- 子公司分红、处置和其他投资收益；
- 债务、利息、税、重大支出、融资能力和契约。

### 3. 法定和监管顺序

按目标法域和公司章程核对：税后利润先弥补亏损，再提取法定公积；随后考虑任意公积、股东会决议和可分配余额。保险子公司上划还受自身偿付能力、资本质量、流动性、业务增长、监管措施及其他准备要求约束。

### 4. 静态压力提示

只选择与当前结论直接相关且期间、范围可比的高信息指标，例如：

- 年度可动用资金表所列子公司分红流入 / 母公司年度对外现金分红；
- 拟派或年度股息 / 母公司法定可供分配利润或当期净利润。

这些比率必须标为“静态压力提示”，不得称“完整法定可分配能力”“可持续派息上限”或现金调度结论。不要把资金流入减对外分红后的机械余额称为可自由支配现金，也不堆叠多个弱覆盖率。完整判断还需要弥补亏损、公积、章程和决议、现金受限、债务、子公司实际上划、资本计划及监管限制。

### 5. 母公司分红表顺序

紧凑表按以下顺序列：

1. 投资收益附注中的股利收入总额；
2. 关联方附注中的主要子公司逐家确认明细及合计；
3. 成本法会计政策的宣告确认节点；
4. 年度可动用资金表所列子公司分红流入及逐家构成；
5. 各表间未归属或跨口径差额；
6. 现金流量表和应收股利旁证；
7. 当前能够停到的确认、宣告、年度资金流入、支付或到账层级；
8. 母公司净利润、未分配利润、现金、法定与资本约束。

## 输出

紧凑模式最多两张表：

1. 服务结果或税前利润至归母利润勾稽桥；
2. 股利确认—宣告政策—年度资金流入—未归属/跨口径差额—现金旁证—母公司约束链。

连续追问只引用前表并补口径边界，不重复全部数字。最后给三个证伪点。
