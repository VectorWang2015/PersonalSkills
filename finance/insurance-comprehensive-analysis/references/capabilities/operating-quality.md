# 经营质量与利润绝对变化桥

完成文档扫描和分业后运行。先读取管理层正式归因，再重建桥；不能因投资收益下降或CSM释放变化而替代公司披露的主因。

## 正式归因

从报告正文、管理层讨论、业绩说明或附注提取：

- 管理层对保险服务结果、税前利润、净利润和重要分部变化的解释；
- 主体、期间和指标口径；
- 页码、表名、列名或文本行号。

标为“报告披露/公司归因”，再用可复算桥检验。桥只支持一部分时，分别写公司归因、量化旁证和未解释差额。

## 计算和排序

对每项驱动：

`带符号变化额 = 本期同口径金额 - 上期同口径金额`

`排序值 = |带符号变化额|`

保险服务结果和利润桥均按排序值从大到小展示。前三大变化无法解释大部分目标变动时，不给确定主因。

## 综合金融集团归属桥

报告有业务/分部至集团归属的正式勾稽时，第一张核心表必须使用该表，而不是另行拼接。至少同时列：

- 业务或分部净利润；
- 其中归属于集团母公司的对应贡献；
- 少数股东损益；
- 其他业务及合并抵销；
- 集团合并净利润和归母净利润。

业务净利润反映该业务全部股东口径，集团归属贡献才进入集团归母桥。只有报告口径支持时才复算“业务净利润 = 集团归属贡献 + 少数股东”；集团归母应由各归属贡献和合并抵销闭合，不得把各业务净利润直接相加。

## 保险服务结果桥

显式检查：

- CSM当期释放；
- 非金融风险调整释放或变化；
- 亏损部分确认与转回；
- 当期服务赔付、费用和其他经验差异；
- 过去服务相关履约现金流变化；
- 保险获取现金流分摊；
- 分出再保险的净影响；
- 公司披露的其他服务项目。

CSM释放只是服务结果组成项。即使CSM释放增加，亏损部分、经验差异、风险调整或费用也可能使保险服务结果下降。CSM余额变动桥与当期服务结果桥不得混写。

对寿险或长期健康险，先判断报告是否提供本期、上期或可复算变动表。有数据时分别闭合以下三条桥，绝不相互混加：

### 1. 保险服务结果桥

按报告实际披露的三桶或其他桶闭合，例如：

`CSM摊销 + 非金融风险调整变动/释放 + 营运偏差及其他 = 保险服务业绩及其他`

如果“营运偏差及其他”未继续拆出亏损部分、经验差异或获取费用，只能停在该桶，不能用概念清单补成更细桥。

### 2. 营运利润至净利润桥

按报告定义分别闭合：

`保险服务结果 + 投资服务业绩 + 其他税前项 = 税前营运利润`

`税前营运利润 + 所得税 = 营运利润`

`营运利润 + 短期投资波动 + 一次性重大项目及其他 = 净利润`

该桥是寿险业务净利润口径，不自动等于归属于集团母公司的贡献。

### 3. CSM余额桥

按带符号项目闭合：

`期初CSM + 新业务贡献 + 预期利息 + 调整CSM的估计变更 + 其他 - 当期摊销 = 期末CSM`

CSM余额方向与当期保险服务结果、营运利润或净利润是不同问题。

证据不足时：

- 数据足以同口径勾稽时，量化CSM释放、非金融风险调整、亏损部分、经验差异和其他重要项，并列未解释差额；
- 只有“保险服务业绩及其他”、收入、费用或管理层概括时，明确分析只到结果层；
- 仅列“还应检查CSM、风险调整、亏损部分、经验差异”的概念清单，不算已经完成服务内部桥，也不能据此评价这些项目的方向或大小。

## 税前利润至归母利润桥

显式检查：保险服务结果、保险财务损益、利息/股息/租金、投资买卖价差、公允价值、减值/信用/汇兑、处置/并表/会计变动、税、少数股东及其他一次性项目。

若同一张桥表混合税前利润表项目、所得税和少数股东损益，标题必须写：

**税前利润至归母利润同比勾稽桥**

桥的层级为：

1. 税前经营项目变化，勾稽至税前利润变化；
2. 加所得税费用变化，勾稽至净利润变化；
3. 减少数股东损益变化，勾稽至归母净利润变化。

不得把各税前项目列名为“税后归母贡献”或“对归母利润的逐项贡献”。除非公司正式披露逐项税后、归母归因，否则明确写“未作逐项税后归因”，只提供跨层级勾稽。

一次性处置、并表、会计政策/估计、税和比较基数与持续承保、投资分栏。投资项目可以是重要驱动，但不能在完整桥或公司归因不支持时被指定为唯一主因。

## 分业补充

### 财险

结合公司定义的综合成本率、赔付率和费用率，检查价格、暴露量、频率、案均损失、巨灾、准备金发展、险种/渠道结构、费用和再保险。不固化95%评价线。

### 寿险和长期健康险

结合新业务保费、期交/趸交、渠道、平均人力、继续率、毛/扣偿后VNB、风险分散和VNB率分母。服务内部桥按上一节的证据层级决定是否量化。季度人均值不无条件年化，VNB不按固定比例映射CSM、营运利润、现金或分红。

## 紧凑输出和追问

紧凑模式优先保留：一行身份、三条结论、最多两张核心表、三个证伪点。桥表最多展示绝对变化最大的项目、层级小计和未解释差额。

连续追问如果只问口径或边界，应引用上一问的桥和数字，只补：为何不能画等号、缺失证据及证伪条件；不重复整张表和全部结论。

## 证伪点质量

三个证伪点必须针对本次核心结论的当前可观察反例。例如：

- 业务净利润与集团归属贡献不一致，推翻“业务利润可直接并入集团归母”；
- 期末CSM低于期初，推翻“CSM余额增长”；
- 净投资收益率下降或某保险法人综合收益率下降，推翻“投资回报全面改善”；
- 个体偿付能力或子公司上划受限，推翻“集团资本即可保证分红持续”。

“未来若重述就重算”“以后若披露更多数据”只是维护条件，不算证伪当前结论。
