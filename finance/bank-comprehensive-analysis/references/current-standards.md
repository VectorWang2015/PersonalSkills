# 中国商业银行现行口径速查

`verified_as_of: 2026-09-03`

本文件只记录会改变分析决定的现行规则。若用户要求“当前”“是否达标”或执行日期晚于核验日，先重新打开官方链接核对修订、废止、银行组别和单行第二支柱要求；不能把本文件当永久法规副本。

## 资本与风险加权资产

权威来源：[国家金融监督管理总局《商业银行资本管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1134197&itemId=4214)，国家金融监督管理总局令2023年第4号，2024年1月1日起施行。

### 银行档次

- 第一档：并表口径调整后表内外资产余额不低于5000亿元，或达到规定的境外债权债务规模/占比。
- 第二档：并表调整后表内外资产余额不低于100亿元但不属于第一档；或余额低于100亿元但存在境外债权债务。
- 第三档：并表调整后表内外资产余额低于100亿元且境外债权债务为零，按办法附件23执行简化规定。

分析上市大中型银行通常落在第一档，但不得仅凭名称猜测；以报告披露和当期规则为准。

### 第一、第二档主要最低要求

| 指标 | 要求 |
|---|---:|
| 核心一级资本充足率 | 不低于5% |
| 一级资本充足率 | 不低于6% |
| 资本充足率 | 不低于8% |
| 储备资本 | RWA的2.5%，由核心一级资本满足 |
| 杠杆率 | 不低于4% |

最终适用目标不是简单的5%/6%/8%。还应检查：

- 逆周期资本要求；
- 国内或全球系统重要性银行附加资本；
- 第二支柱对资产组合或单家银行提出的额外要求；
- 系统重要性银行附加杠杆率；
- 总损失吸收能力等另行适用要求。

### 国内系统重要性银行

权威来源：[中国人民银行《系统重要性银行附加监管规定（试行）》](https://www.pbc.gov.cn/zhengwugongkai/attachDir/2025/11/2025111914581986726.pdf)。

- 第一至第五组附加核心一级资本要求分别为0.25%、0.5%、0.75%、1%、1.5%。
- 附加杠杆率为附加资本要求的50%，由一级资本满足。
- 同时属于国内和全球系统重要性银行时，附加资本不叠加，取孰高。

必须取得报告期适用的银行名单和组别；不得把“系统重要性银行核充率8.5%”写成统一常量。

### RWA与损失准备

- 风险加权资产由信用风险、市场风险和操作风险加权资产组成。
- 信用风险可采用权重法或经监管验收的内部评级法；未覆盖部分使用权重法。市场风险和操作风险也按办法及附件计量。
- RWA方法、银行档次、模型变更、输出底线和并表范围会改变跨行可比性。
- RORWA与“资产减值准备/RWA”均不是《资本办法》规定的资本监管指标。

权威来源：[实施《商业银行资本管理办法》相关事项的通知](https://www.nfra.gov.cn/cn/view/pages/governmentDetail.html?docId=1134198&itemId=861)。权重法损失准备过渡期结束后，用于资本处理的损失准备最低要求原则上是不良资产余额100%对应的损失准备；该规则不能与会计ECL或贷款拨备覆盖率混为一体。

## 金融资产风险分类

权威来源：[《商业银行金融资产风险分类办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1095372&itemId=4214)，原银保监会、中国人民银行令2023年第1号，2023年7月1日起施行；旧存量业务应于2025年12月31日前完成重新分类。

### 范围与五级分类

- 覆盖表内承担信用风险的贷款、债券和其他投资、同业资产、应收款项等，以及承担信用风险的表外项目。
- 不覆盖交易账簿金融资产和衍生品交易形成的相关资产。
- 正常、关注、次级、可疑、损失五类；后三类合称不良资产。

### 关键最低分类

- 除7天内操作/技术性短期逾期外，发生逾期至少关注。
- 逾期超过90天至少次级。
- 逾期超过270天至少可疑。
- 逾期超过360天归为损失。
- 已发生信用减值至少次级；ECL占账面余额50%以上至少可疑，90%以上归为损失。
- 非零售债务人在本行超过10%的债权被分为不良时，原则上本行对其所有债权归为不良。
- 重组观察期至少连续两个还款期且不得低于一年。

不良偏离度、广义不良率只能作分析诊断；异常值不能单独证明银行故意隐藏不良。

## 会计预期信用损失

权威来源：[财政部《企业会计准则第22号——金融工具确认和计量》](https://kjs.mof.gov.cn/zhengcefabu/201704/P020170406398225042083.pdf)。

- 对摊余成本、FVOCI等适用项目以预期信用损失确认损失准备。
- 信用风险自初始确认后显著增加时，计量整个存续期ECL；未显著增加时，计量未来12个月ECL。
- 计量应考虑合理、有依据的信息，包括前瞻性信息。

原书的正常1%、关注2%、次级25%、可疑50%、损失100%是历史监管叙述，不能作为当前会计减值算法。

## 贷款损失准备监管

权威来源：[金融监管总局《商业银行贷款损失准备管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=276276&itemId=4214)。

- 贷款拨备率＝贷款损失准备/各项贷款余额。
- 拨备覆盖率＝贷款损失准备/不良贷款余额。
- 办法写明的基本标准分别为2.5%和150%，以较高要求为监管标准。
- 监管机构可随经济周期和按单家银行风险作动态、差异化调整。

因此报告中应分别展示“披露值”“基本标准”“该行当期适用要求”。拿不到单行要求时不得直接声称监管达标或安全，更不得把120%、150%、200%当统一质量评级线。

## 流动性风险

权威来源：[金融监管总局《商业银行流动性风险管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=180252&itemId=4214)，中国银保监会令2018年第3号，2018年7月1日起施行。

| 银行范围 | 指标 | 最低要求 |
|---|---|---:|
| 资产规模不小于2000亿元 | 流动性覆盖率LCR | 100% |
| 资产规模不小于2000亿元 | 净稳定资金比例NSFR | 100% |
| 全部商业银行 | 流动性比例 | 25% |
| 全部商业银行 | 流动性匹配率 | 100% |
| 资产规模小于2000亿元 | 优质流动性资产充足率 | 100% |

经监管批准，小于2000亿元的银行也可适用LCR和NSFR。监管办法明确单一流动性指标有局限，必须结合期限、币种、融资集中度、压力测试和应急融资能力。

## 执行不变量

1. 规则结论写明法域、规则、施行日、核验日和适用对象。
2. 公司报告中的监管指标以其披露定义和并表范围为起点。
3. 不把作者指标、经验阈值或历史银行排名称为监管要求。
4. 当前规则与书中表述冲突时，书中内容只作历史来源；当前分析以官方规则为准。
5. 银行特定第二支柱、窗口指导或未公开监管要求不可得时，明确这一限制。
