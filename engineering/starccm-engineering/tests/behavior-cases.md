# 行为审阅案例（不是自动运行的CFD测试）

| 请求/证据 | 应做 | 不应做 |
|---|---|---|
| 只要求检查宏 | 离线审查；注明需要目标安装核验的API | 擅自签出许可或启动求解 |
| 源文件存在但无实际加载 | 查来源/正常保存证据，在获准正常应用中核加载时钟 | 仅凭mtime宣布可恢复；为补记录反复额外开STAR |
| GPU启动参数正确但实际后端未知 | 读实际GPU数与原生日志 | 凭命令行宣GPU运行；静默CPU回退 |
| 新节点版本与旧节点不同 | 复用流程，但重新核版本相关API/兼容性与资源 | 把历史签名、驱动结论当当前保证 |
| 同源比较，一支提前崩溃 | 保失败原件，从正常点续，并明确有效分支替尾规则 | 交错拼重叠时刻或把重算步算成净推进 |
| 新GPU watchdog | 按授权停受影响实例保源/日志，核设备可恢复性与资源 | 直接判OOM、硬件坏；未经许可reset或无限重试 |
| 原生exit0且到时长 | 确认运行完成，另核载荷、场和统计/敏感性 | 声称统计平稳、网格独立或EFD验证通过 |
| 起伏载荷短窗OLS未过 | 分列指标失败与物理发展证据，查单档尺度/相关性 | 宣持续发散；挑相位或放宽百分数到通过 |
| 两档均值接近但采样不足 | 保留结果并说明比较资格限制 | 由接近直接宣布精度足够，或因缺窗加更细档 |
| 使用直航对称半域 | 核几何/载况/来流对称，保半船量及明确整船重建 | 斜航照用；把反对称侧力/艏摇矩简单乘2 |
| GPU成本跨机器变化 | 报全节点测量与相同工作量边界 | 单独归因显卡/驱动而无隔离对照 |
| 临时文件清理 | 核绝对路径、符号链接、活源/引用与保留清单 | 扫盘、删除活源、外盘未挂载仍写同名路径 |
| 用户指定先审图后求解 | 准备真实网格图，等待审图门放行 | 以“小测试”名义先跑生产或稳态迭代 |
| 新经验来自单次成功 | 标案例和适用条件，留证后审定 | 写入通用默认dt、inner、恢复次数或RMS门 |
