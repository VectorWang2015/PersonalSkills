# 真实媒体与有界保留

## M01 [原则] 求解前规划输出，不为动画重造物理

按用户交付需求和目标物理量，预先估算渲染、IO、存储成本与合理采样；不要逐步保存完整场文件。
船舶自由面任务可选择速度、压力、自由面高程及网格视图；这是领域相关输出清单，不是所有模型都存在自由面。
动态输出应支持所声称的周期/相位范围；若未覆盖，明确缺口，不制造中间场补齐。

帧manifest建议字段：`case / branch / source_id / actual_physical_time / field_function / unit / pressure_reference / view / color_range / file / stage_status`。

## M02 [原则] 原生场与视觉表达各有语义

- 读回所选实际物理字段；压力注明静压/表压/扰动及参考，自由面注明是何等值面或重建量。
- 固定相机与色标用于时序比较，说明截幅/饱和和展示镜像；不得美化隐藏异常。
- 标注实际存图时钟，最近邻图不能标成要求的精确时刻。插值画面若用于展示须显式声明且不可冒充原生物理解。
- 几何表面图不是体网格；网格图按适用问题涵盖全域、局部表面、关键截面、壁层和过渡。
- 启动、诊断、失败和生产阶段分开标注。旋转静图不是流场动画；无有效轨迹时交付说明而非造帧。

## M03 [原则] 可追溯交付而非PNG计数

按需编码通用视频、保留关键时刻图及简明说明；检查可解码、帧顺序/数量和manifest对应，并抽查字段与画面内容。哈希不同或帧数正确不能单独证明物理正确。

展示真实关键图和目标量小表，说明做完什么、误差/差异如何定义、不能迁移什么及剩余限制。给原始CSV/manifest和必要可重新加载状态的入口；不把完整日志堆给非专业用户代替结论。

## M04 [原则] 保留事实不等于永久保留每份大文件

- 先列保留清单：原始/受保护输入、活源、最新正常恢复点及必要有界备份、有价值终态、不可替代异常现场、小证据与失败结论。
- 已淘汰且可重建的大状态、临时中转和重复包仅在当前授权下逐路径审定；失败证据可以保留小摘要/设置/日志片段，不删事实。
- 删除/移动前核对resolved绝对路径、项目归属、symlink实际目标、活跃持有者及引用关系；不动运行读取中的源、用户保护项和他人数据。
- 外盘写入前核真实挂载与设备身份，避免落到未挂载的同名内盘目录；移动/软链接不是独立备份。
- 转移验证成功返回、稳定元数据/大小、持久化及必要原生读回；按风险/要求选校验，不把反复全量hash作为语义验证替代。
- 记录实际释放量、保留源和小证据位置；介质变更或清理权限不足时报告，不自行扫盘或改挂载。
