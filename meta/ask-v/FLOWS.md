# Manual skill combinations

- Before a plan or design change: use `grill-with-docs` when the discussion belongs to a project and should capture terms or decisions; use `grill-me` for discussion without project documentation.
- When another person holds information you need: use `to-questionnaire`; return to the design discussion once their answers arrive.
- Before delivery or integration: use `code-review`, pinning the integration reference or branch point as the review's fixed point.
- Whenever an agent's reply is unclear: use `wait-what`, then continue the interrupted workflow.
- After a stretch of work or a session that went wrong: use `retro` in that session while its evidence is available.
- Routine small changes need no manual skill unless the situation calls for one.
