# 阶段 0 — 来源建档与整书理解

## 目标

在提取方法之前，建立一个可复查的来源底座和全书论证地图。Adler 的结构、解释、批判与应用问题可以作为阅读镜头，但不是固定题数或格式要求。阶段 0 的产物应帮助后续角色定位原文、识别作者真正的主张，并看见主张成立所依赖的条件。

## 输入边界

- 以用户提供或授权访问的原书为主要来源，不用模型记忆补齐缺页或缺章。
- 记录书名、作者、版本、出版时间、语言、文件来源和处理范围。不同版本或译本不得默认为同一来源。
- 如文本来自 OCR、扫描件或自动转写，标记页码漂移、乱码、表格丢失、脚注缺失等问题。
- 用户的目标场景、受众和交付范围可以影响“提取什么”，但不能改变“作者说了什么”。
- 若任务属于重新蒸馏，遵守 `08-redistill-and-merge.md`：盲态阶段不得读取旧 skill、旧测试、旧总结或旧评审结论。

## 1. 建立来源清单与定位体系

为每个输入分配稳定的 `source_id`，并记录内容摘要值或其他版本指纹。定义后续所有 extractor 都能复现的 locator：

```yaml
source_id: pca-en-2005
title: Poor Charlie's Almanack
edition: first-edition-2005
language: en
content_fingerprint: "<sha256 或仓库版本标识>"
coverage: "完整正文；不含索引"
locator_scheme: "part > chapter > section > printed-page > paragraph"
known_issues:
  - "第 143 页表格由 OCR 转写，列边界不可靠"
```

精确锚点优先使用出版物本身的章节、节、印刷页码、表号或脚注号；若来源没有稳定页码，再使用段落号、行号、时间戳或其他可复现位置。仅写“第三章”通常不够精确。

## 2. 建立全书论证地图

根据书的实际结构回答以下问题，不为满足数量而硬凑：

### 结构

- 作者在解决什么核心问题？
- 各部分承担什么功能，彼此是递进、并列、因果、反驳还是例证？
- 哪些章节超出本次蒸馏范围，为什么？

### 解释

- 哪些词有作者特定含义？
- 哪些是作者明确陈述的命题，哪些是从多处材料综合出的模式？
- 主张由何种证据支撑：数据、案例、演绎、类比、经验、权威引用或仅是断言？
- 多处内容是否存在张力、例外或版本差异？

### 批判

- 主张依赖哪些时代、制度、行业、文化、样本或身份条件？
- 作者是否把相关性写成因果、把成功案例写成一般规律，或遗漏失败样本？
- 最强反例和反方解释是什么？
- 哪些主张需要当前事实、法规或外部证据才能安全应用？

### 应用潜力

- 哪些内容有明确的触发条件、动作和结果，可能形成可执行契约？
- 哪些更适合作为术语、案例、边界、证据或背景，而不是独立 skill？
- 目标用户的真实任务中，哪些问题可能受益？这只是待评测假设，不是录取结论。

## 3. 分离来源、综合与推断

阶段 0 起就使用三种声明标签：

- `explicit`：作者在给定锚点直接表达；
- `synthesized`：由多个已列锚点综合，措辞不是作者原句；
- `inferred`：蒸馏者为应用或解释提出，书中没有直接给出。

批判意见、现代化改写和领域适配通常属于 `inferred`。它们可以有价值，但必须与原书主张分开，并写出依据与不确定性。

## 4. 生成覆盖地图

记录已读、未读和低置信度区域，防止“读过目录和几个重点章节”被误报为整书蒸馏。对于超长来源，可以先建立章节地图，再按风险和候选密度分块；相邻块保留少量重叠或共享上下文，以免跨段落定义被截断。

```yaml
- source_id: pca-en-2005
  range: "Talk 5, pp. 227-248"
  status: reviewed
  reviewer: "worker-id 或人工记录"
  confidence: high
  notes: "包含心理倾向清单；两页脚注未提取"
```

## 进入阶段 1 的就绪条件

- 来源版本、处理范围和定位规则清楚，关键锚点可复现；
- 全书主要结构与论证链足以指导分工；
- 已知缺失、OCR 问题和版本冲突被显式记录；
- 作者主张、综合结论与蒸馏者推断没有混写；
- 对“可做成 skill”的内容只有候选假设，没有提前把摘要当成结论；
- 若目标、版本或高风险范围存在会实质改变结果的不确定性，已向用户确认；否则不设置形式化确认关卡。

## 常见失败

- 用现有书评、旧 skill 或模型记忆代替原书；
- 只写主题摘要，不记录论证证据、反例和适用条件；
- 锚点只到章级，后续无法核对原句；
- 把译者注、编者注、案例参与者的话当成作者主张；
- 因作者多次重复某句话就提前认定它值得成为 skill；
- 为满足固定条数制造术语、局限或候选。
